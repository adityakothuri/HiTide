# Photon 2.0 and voice live test

Related: [[Photon Outreach]], [[Stage 3 Stopped in water]], [[Decisions]], [[2026-11-07 Photon live test]]

**Why:** the Photon prize requires Photon 2.0 (beta). The "Best Voice Agent" prize wants real calls, low latency, and memory of the call once the conversation moves back to text.

**Setup, all scripted and repeatable:**
- `uv run python -m scripts.photon2_enroll --write-env` enrolls A, B and C on the shared iMessage line. Each recipient gets their **own line and agent sender**, saved in `PHOTON2_AGENT_MAP`.
- `uv run python -m scripts.elevenlabs_setup` creates or updates the ElevenLabs agent:
  - prompt, `{{opening_line}}`, variables, `driver_status` data collection, end_call and voicemail_detection
  - Flash v2 TTS, ulaw 8 kHz, Gemini 2.5 Flash
  - imports the Photon SMS number `+13392102263` as a SIP trunk (`sip.photon.codes:5061`, TLS)
- Photon inbound calls point at `sips:sip.rtc.elevenlabs.io:5061`, set through the API, which gives us a call-in hotline.

**Bugs found live and fixed (with tests):**
1. **Wrong sender:** a shared line gives each recipient a separate agent, so one stored agent ID sent B's and C's texts from A's line. Fixed with the per-recipient agent map.
2. **"Override for field 'first_message' is not allowed by config":** ElevenLabs rejected the first-message override on SIP calls. The first message is now the `{{opening_line}}` variable, which needs no override permission.
3. **Call setup outlasts the timeout:** ElevenLabs' outbound-call endpoint answers only once the SIP call connects, which took 10–20 s. That exceeded both the 10 s HTTP timeout and the runner's 8 s send budget, so the call ID was lost and the transcript never processed. Calls are now placed in a background task (`_call_then_watch`) with a 45 s timeout.
4. **Talking to voicemail:** the agent spent 39 s talking to a voicemail box. Added `voicemail_detection`, which leaves one short message and hangs up.

**Live run (full demo, photon2):**

|---|---|---|

The earlier solo test call to A connected and lasted 31 s. The agent ended it with end_call, the outcome classified as `unknown` (the caller never said safe or help), and the cautious follow-up text went out.
