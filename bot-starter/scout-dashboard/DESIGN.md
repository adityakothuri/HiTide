# Scouting dashboard

An operational scouting desk: cool slate canvas, dark green selection, ink text, compact tabular numbers. Left-hand leaderboard, right-hand detailed opponent sheet, persistent runtime and Apply controls. Mobile stacks the roster above the details. Typography uses Georgia for the main name and system sans for controls and dense data. Colors: canvas #eef2f4, paper #ffffff, ink #182d26, muted #53675e, accent #245d43, rules #d5ddd3. This is an urgent local tool, built directly from the user's explicit workflow.
